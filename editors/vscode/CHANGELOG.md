# Changelog

The extension's version is the Piton release it goes with.

## 0.1.41

First Marketplace release.

- Highlighting from a TextMate grammar.
- Diagnostics, completion, hover, go-to-definition, find-references, rename,
  symbols, semantic highlighting, inlay hints, code actions, formatting,
  folding, and selection ranges from `piton lsp`.
- Indentation on Enter for colon lines, and back out of a dictionary or anchor
  on a blank line.
- Commands to jump between Piton source and compiled output, and to preview
  the compiled output beside the source.
- `piton.server.path`, `piton.server.enabled`, and `piton.formatOnSave`
  settings.

# Piton for Kate and KWrite

Generated by `piton grammar`.

```sh
mkdir -p ~/.local/share/org.kde.syntax-highlighting/syntax
cp piton.xml ~/.local/share/org.kde.syntax-highlighting/syntax/
```

For diagnostics and completion, enable Kate's LSP Client plugin and add:

```json
{ "servers": { "piton": { "command": ["piton", "lsp"], "highlightingModeRegex": "^Piton$" } } }
```

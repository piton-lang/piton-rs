# Piton for Emacs

Generated by `piton grammar`.

```elisp
(add-to-list 'load-path "/path/to/piton/editors/emacs")
(require 'piton-mode)
```

`piton-mode` registers itself with both `eglot` and `lsp-mode`; either will
start `piton lsp` when you open a `.pi` file. `M-x piton-format-buffer` runs the
canonical formatter.

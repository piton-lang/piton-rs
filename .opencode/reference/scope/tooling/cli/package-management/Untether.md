# Untether

## Description

Moved an installed package from to the specRoot/untetherd directory while also rewriting any imports

## Command Name

untether

## Positional Arguments

null

## Named Arguments

null

## Positional Args

```
packageName: the name of the package to untether
```

## Named Args

```
as: the name to give the untethered package
no-rewrite: Don't rename any imports, simply move the package
```

# Check

## Description

Checks specific files or the project and reports errors

## Command Name

check

## Positional Arguments

```
path: Optional file or glob. Defaults to the project.
```

## Named Arguments

null

## Emit

false

## Validate

- syntax
- imports
- references
- types
- inheritance
- composition
- exports
- circular-dependencies

## Diagnostics

```
errors: true
warnings: true
```

## Exit Code

```
success: 0
errors: 1
```

# Loc

## Description

Counts lines of Piton source for specific files or the project

## Command Name

loc

## Positional Arguments

```
path: Optional file or glob. Defaults to the project.
```

## Named Arguments

null

## Emit

false

## Count

- total
- code
- comments
- blank

## Group By

file

## Summary

true

## Diagnostics

```
errors: false
warnings: false
```

## Exit Code

```
success: 0
```

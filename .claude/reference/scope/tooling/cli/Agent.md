# Agent Cli

## Description

Launches the specified agent with Piton fluency using the output of the [GenerateFluencyPrompt](../../../../skills/generate-fluency-prompt/SKILL.md) skill, which is FLUENCY_PROMPT.md in the project root.

## Command Name

agent

## Positional Arguments

```
agent: Which agent to run [ claude ]
```

## Named Arguments

```
print-fluency: Print the entire fluency prompt
```

# Document Highlight

## Description

Highlighting every use of the symbol under the cursor in the current file

## Summary

Highlighting marks the places references would list, limited to the current file, with each declaration marked as a write and every other place as a read. Nothing is highlighted when the cursor is not on a symbol that [SymbolIdentity](../model/SymbolIdentity.md) describes, which includes `self`, `this`, and `super`, and prose.

Links in this document point at reference files. Read one when the work touches what it describes.
